# 🧾 Alterar / Adicionar informações no Layout da O.S

## 📌 Objetivo

Permitir a inclusão ou alteração de informações personalizadas no layout de impressão da Ordem de Serviço (O.S).

---

## 🧭 Quando utilizar

Utilize este procedimento quando:

* Houver solicitação do cliente para alterar o layout da O.S
* For necessário incluir informações adicionais no documento

**Exemplo:**
Adicionar mensagem: *“Orçamento válido por 30 dias”*

---

## 🛠️ Passo a passo

### 1️⃣ Acessar o layout da O.S

1. Abrir o sistema **Bmsoft** (`master.exe`)
2. Acessar o módulo `O.S`
3. Selecionar uma O.S como modelo (exemplo)
4. Clicar em `🖨️ Imprimir`
5. Selecionar o layout que será alterado
6. Segurar a tecla `SHIFT` e clicar em `OK`
7. Digitar senha solicitada para acessar o Reports

➡️ O editor **FastReport** será aberto para edição

---

### 2️⃣ Realizar a edição

* Localize o campo onde deseja inserir ou alterar a informação
* Adicione a informação desejada diretamente no layout

---

### 3️⃣ Visualizar alterações

* Pressione `CTRL + P` **ou**
* Clique no ícone de visualização (lupa com folha)

➡️ Isso permite validar como o layout será impresso

---

### 4️⃣ Salvar alterações

* Clique no ícone de salvar `💾` para gravar o layout

## ⚠️ Observações

* Sempre utilize uma O.S de exemplo para evitar alterações indevidas em documentos reais
* Valide o layout antes de finalizar, garantindo que as informações estejam corretamente posicionadas
* Alterações no layout impactam todas as impressões que utilizam esse modelo
* Recomenda-se realizar backup do layout antes de qualquer modificação
