# 🧾 Gerar arquivo mensal de notas emitidas

## 📌 Objetivo

Gerar o arquivo consolidado das notas fiscais emitidas no período, para envio à contabilidade e apuração de impostos.

---

## 🧭 Quando utilizar

Utilize este procedimento nos seguintes cenários:

* 📅 Fechamento mensal para envio à contabilidade
* 📊 Conferência de notas emitidas no período
* 🧾 Necessidade de auditoria ou validação fiscal

---

## 🛠️ Passo a passo

### 🔹 1. Acessar o módulo de NFe

1. Abra o sistema `Master.exe`
2. Clique no módulo `🌎 NFe`
3. Acesse o menu `Extras ⬇️`
4. Clique em `📁 Gerar arquivo mensal`

---

### 🔹 2. Configurar os parâmetros do arquivo

1. Informe o **período desejado**:

   * Data inicial
   * Data final

2. Selecione os **tipos de notas** que devem compor o arquivo:

   * Autorizadas
   * Canceladas
   * Denegadas

3. Defina as **séries de notas** que serão consideradas

4. No campo **Salvar em**:

   * Escolha a pasta onde o arquivo será gerado

---

### 🔹 3. Gerar o arquivo

1. Após conferir todas as informações
2. Clique em **Gerar**
3. Aguarde a finalização do processo
4. Acesse a pasta selecionada para localizar o arquivo

---

## ⚠️ Observações

* 📌 Certifique-se de selecionar corretamente o período para evitar divergências nos dados
* 📌 Recomenda-se incluir todas as situações de notas (autorizadas, canceladas e denegadas) para envio completo à contabilidade
* 📌 Verifique se possui permissão de gravação na pasta selecionada
* 📌 O arquivo gerado deve ser validado antes do envio, se necessário
