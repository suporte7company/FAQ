# 🧾 Formulário – Cadastro de Operações Fiscais

## 📌 Objetivo

Coletar, junto à contabilidade, todas as informações fiscais necessárias para o correto cadastro de operações no sistema, garantindo conformidade tributária e funcionamento adequado dos módulos envolvidos.

---

## 🧭 Quando utilizar

Utilize este formulário sempre que:

* 🆕 For necessário cadastrar uma nova operação fiscal no sistema
* 🔄 Houver alteração de regras fiscais de uma operação já existente
* 🧩 Implantação inicial do sistema (parametrização completa)

## ⚠️ Observações Importantes

* Todas as informações devem ser fornecidas pela contabilidade para evitar inconsistências fiscais.
* O preenchimento incorreto pode impactar diretamente na emissão de notas fiscais e apuração de impostos.
* Em caso de dúvidas, validar previamente antes de realizar o cadastro no sistema.

---

## 🔗 Relação com o Sistema

Este formulário faz parte do processo de utilização do módulo **Cadastros**, sendo etapa obrigatória para garantir que as operações fiscais estejam corretamente parametrizadas antes do uso nos módulos de faturamento, estoque e financeiro.
