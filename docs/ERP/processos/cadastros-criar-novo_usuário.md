# 🧾 Cadastro de novo usuário

## 📌 Objetivo

Realizar o cadastro de um novo usuário no sistema, garantindo acesso conforme o perfil de utilização.

---

## 🧭 Quando utilizar

Utilize este procedimento nos seguintes cenários:

* 👤 Admissão de novo funcionário
* ⚙️ Colaborador que passará a utilizar o sistema
* 🔄 Necessidade de criar um novo acesso individual

---

## 🛠️ Passo a passo

### 🔹 1. Criar o usuário no sistema

1. Abrir o sistema `BMSoft (master.exe)`
2. Acessar o módulo `Cadastros`
3. Clicar em `Outros ⬇️`
4. Selecionar `Usuários`
5. Clicar em `Incluir`
6. Preencher os campos obrigatórios:

```
Nome | Apelido | Login | Senha
```

7. Clicar em `OK`

---

### 🔹 2. Vincular o usuário a um perfil (grupo)

1. Abrir o sistema `BMSoft (master.exe)`
2. Acessar `⚙️ Manutenção`
3. Clicar em `⚙️ Configurador`
4. Informar a senha solicitada
5. No menu lateral esquerdo, localizar o `Grupo (Perfil)` desejado
6. Selecionar o usuário recém-criado
7. Arrastar o usuário para o grupo correspondente
8. Clicar em `💾 Salvar`

![colocando usuario no perfil de acesso - ERP-2](https://github.com/user-attachments/assets/0a1efba9-7352-42a0-9304-86989eb33e91)

---

## ✅ Resultado esperado

* Usuário cadastrado com sucesso
* Acesso liberado conforme permissões do grupo vinculado

---

## ⚠️ Observações

* O vínculo com um **Grupo (Perfil)** é obrigatório para acesso ao sistema
* Sem essa vinculação, o login será criado, porém **não será possível acessar o sistema**
* Defina o perfil conforme a função do usuário para evitar acessos indevidos
