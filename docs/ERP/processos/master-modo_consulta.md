# 🧾 Ativar modo consulta no sistema

## 📌 Objetivo

Restringir o acesso do cliente ao sistema, permitindo **somente consulta aos dados já existentes**, quando não houver mais licença ativa de uso.

---

## 🧭 Quando utilizar

Utilize este procedimento nos seguintes cenários:

* 👤 Cliente não renovou o contrato de uso do sistema
* 💰 Situação validada pelo setor financeiro para bloqueio de uso
* 🔒 Necessidade de manter acesso apenas para consulta de informações já registradas

---

## 🛠️ Passo a passo

### 🔹 Pelo módulo Master

1. Abrir o sistema `BMSoft (master.exe)`
2. Acessar o menu `⚙️ Manutenção`
3. Clicar em `💿 Instalação`
4. Informar a **senha de liberação**
5. Acessar a aba `Serial`
6. Marcar a opção `Modo Consulta`
7. Clicar em `OK` para salvar as alterações
8. Fechar o módulo Master e **abrir o sistema novamente** para aplicar a configuração

## ✅ Resultado esperado

* 🔒 Usuário não conseguirá realizar operações no sistema
* 👁️ Acesso liberado apenas para **visualização de dados já cadastrados**
* 🚫 Funcionalidades de inclusão, edição e exclusão ficarão bloqueadas

---

## ⚠️ Observações

* ⚠️ Esta configuração impacta **todos os usuários do sistema**
* 🔄 Caso seja necessário reverter, basta desmarcar a opção `Modo Consulta`
* 🧾 Recomenda-se validar com o setor financeiro antes da configuração
* ⏱️ A alteração só terá efeito após reiniciar o sistema
