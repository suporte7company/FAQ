# 🧾 Liberar permissão para acesso de area remota do cliente para instalação do certificado digital

## 📌 Objetivo
Orientar o processo para acessar a área remota do cliente, no datacenter, a fim de instalar o certificado digital do cliente.

---

## 🧭 Quando utilizar
Utilize este procedimento nos seguintes cenários:


- 🔄 Renovação de certificado digital (expirado ou substituído)
- 📁 Alteração do caminho/local do certificado para instalado no windows

---

## 🛠️ Passo a passo

🔐 1. Acessar  datacenter e pesquisar por Permitir o acesso remoto ao computador.

![Screenshot_619](https://github.com/user-attachments/assets/1445e431-2d92-45a2-ba51-66770dedd298)

  
📂 2. Selecionar a Opção Selecionar Usuários

![Screenshot_620](https://github.com/user-attachments/assets/3e8214ae-d1b6-4caa-ba50-f0ab0d31bf2c)


📥 3. Clicar em Adicionar


![Screenshot_621](https://github.com/user-attachments/assets/7cb2cc5c-bd3a-4343-bd83-5d63f0bd3dd0)



®️ 4. Inserir Usuário do cliente cadastrado no DataCenter e clicar em Verificar Nomes

![Screenshot_622](https://github.com/user-attachments/assets/a28e5beb-e98b-4777-baec-1e716d5a2066)

®️ 5. Apos localizar e inserir o cliente nas permissões , voce estará liberado para poder acessar  a area remota desse cliente pelo conexão de area de trabalho remota com usuario e senha do cliente.
