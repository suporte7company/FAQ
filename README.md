## 🚀 Como contribuir

1. Crie uma **Issue** descrevendo o problema
2. Documente:
   - Sintomas
   - Causa (se souber)
   - Solução aplicada
3. Após validação:
   - Adicione ao README (FAQ ou Soluções Rápidas)
